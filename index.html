Sync settings

Recipes are saved to a private GitHub gist so every phone with Brew Bar sees the same settings.

Classic token with only the gist box ticked: github.com → Settings → Developer settings → Personal access tokens → Tokens (classic). Leave blank on a phone that should only read.

Connect your scale

  1. Tap Connect below. A Bluetooth list opens.
  2. Turn on the scale with the left button.
  3. Choose BOOKOO from the list and tap Pair.

The display lights up when the scale is on. If BOOKOO doesn't appear, wait a few seconds with the list open.
